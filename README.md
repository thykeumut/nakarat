# NAKARAT 🎤

- **Ana Sayfa**: canlı istatistikler, sahne favorileri, nasıl çalışır
- **Karaoke**: 39 şarkılık havuz (Türkçe + yabancı), tam oynatçı kontrolü (durdur/sar/ses/tam ekran), YouTube resmi karaoke videoları
- **Dinle & Bil**: 13 soruluk quiz — video saklanır, sadece ses çalar, 4 şık
- **Temalar**: ☀️ krem / 🌙 karanlık, seçim hatırlanır
